📐 القوانين الأساسية

المميز (Discriminant):
Δ = b² - 4ac
للمعادلة ax² + bx + c = 0
Δ > 0:
جذران حقيقيان مختلفان
القطع يقطع المحور x في نقطتين
Δ = 0:
جذر حقيقي مكرر (واحد)
القطع يمس المحور x في نقطة واحدة
Δ < 0:
جذران مركبان (غير حقيقيين)
القطع لا يقطع المحور x
القانون العام:
x = (-b ± √Δ) / 2a
√Δ يحدد طبيعة الجذور
العلاقة بالرسم البياني:
عدد نقاط التقاطع مع المحور x = عدد الجذور الحقيقية
